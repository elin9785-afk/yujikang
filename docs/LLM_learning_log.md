# LLM 활용 학습 및 코드 개발 기록

이 문서는 프로젝트 대화에서 확인되는 질문과 코드 개발 방향을 정리한 초안이다. 개인적인 학습 성찰과 실제 서버 실행 결과는 학생 본인이 확인하고 보완한다. AI가 제안한 내용과 학생이 검증한 내용을 구분한다.

## 1. 학습 목표

- 자연어로 생물학적 질문을 정의하고 입력·처리·출력 조건을 구체화한다.
- Biopython, Python 반복문·조건문, CSV 및 시각화 도구를 연결한다.
- LLM이 생성한 코드를 그대로 신뢰하지 않고 작은 입력, 예외 조건, 실제 데이터에서 검증한다.
- 다른 사람이 따라 할 수 있는 문서와 소스 코드를 공개한다.

## 2. 프로젝트에서 LLM에 요청한 내용

| 단계 | 실제 대화에서 요청한 내용의 요약 | 제안된 학습/구현 방향 | 검증 상태 |
|---|---|---|---|
| 초기 분석 | GC가 다른 세균의 종결 코돈 비교 | FASTA 읽기, 역상보, 6-frame, CSV | 초기 소스와 기존 결과 공개 확인 |
| 대상 확장 | 실제 세균 9종을 대상으로 분석 확장 | 여러 유전체 입력, 메타데이터 | 최종 서버 소스 대조 필요 |
| 연구 심화 | 두 주제를 통합하고 차별성 확보 | 셔플 대조군, CDS·비CDS, 코딩 밀도 | 제안된 설계, 실제 최종 구현 확인 필요 |
| 난이도 조정 | 어려운 기능 제외, 수업에서 배운 코드 중심 | ENC 제외, 기본 문법과 라이브러리 활용 | 최종 코드 대조 필요 |
| 재현성 | 다른 임의 서열에서도 검증, 처음부터 끝까지 실행 | 테스트, 자동 실행, 입력 및 출력 기록 | 초기 합성 예제 추가; 학생 실행 결과 확인 필요 |
| 문서화 | 교수님 GitHub처럼 전체 코드와 따라 할 수 있는 튜토리얼 | README, 개별 소스, 입력 자료, 학습 기록 | 현재 공개 중 |

## 3. 코드 이해 및 확인할 내용

| 학습 개념 | 코드에서의 역할 | 스스로 설명할 질문 |
|---|---|---|
| SeqIO.parse | FASTA/GenBank 읽기 | 두 형식의 차이는 무엇인가? |
| reverse_complement | 반대 가닥 서열 | 왜 여섯 읽기 틀이 존재하는가? |
| for, if, range | 반복 탐색과 조건 검사 | 왜 3염기씩 이동하는가? |
| 종결 거리 정의 | 코돈 단위 계산 | 종결 포함 거리와 두 종결 사이 내부 길이는 어떻게 다른가? |
| 셔플 대조군 | 염기 개수 유지, 순서 변경 | 무엇을 통제하고 무엇을 보존하지 못하는가? |
| CDS 및 코딩 밀도 | 주석과 좌표 기반 계산 | 겹치는 좌표는 왜 중복 제거해야 하는가? |
| 난수 seed 및 테스트 | 재실행 조건 관리 | 동일한 입력에서 어떤 결과를 비교해야 하는가? |
